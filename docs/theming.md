# Theming the tdmm cards

> Generated by `npm run docs` in `frontend/`. Do not edit by hand.

## Precedence

1. Per-card `theme` override in the card config (applied as inline `--tdmm-*` variables on the card).
2. `--tdmm-*` variables defined in your Home Assistant theme.
3. Home Assistant's own CSS variables (the defaults below).

Every token defaults to a Home Assistant variable, so cards follow light and dark themes automatically.

## Variables

| Variable | Default | Description |
| --- | --- | --- |
| `--tdmm-accent` | `var(--primary-color)` | Accent color for active controls and highlights. |
| `--tdmm-progress` | `var(--primary-color)` | Progress bar fill color. |
| `--tdmm-text` | `var(--primary-text-color)` | Primary text color. |
| `--tdmm-text-secondary` | `var(--secondary-text-color)` | Secondary text and label color. |
| `--tdmm-bg` | `var(--ha-card-background, var(--card-background-color))` | Card background. |
| `--tdmm-chip-bg` | `var(--secondary-background-color)` | Background of chips, tiles and bars. |
| `--tdmm-radius` | `var(--ha-card-border-radius, 12px)` | Corner radius. |
| `--tdmm-gap` | `8px` | Spacing between blocks and items. |
| `--tdmm-font-family` | `var(--ha-font-family-body, inherit)` | Font family. |
| `--tdmm-font-size` | `var(--ha-font-size-m, 14px)` | Base font size. |
| `--tdmm-icon-size` | `24px` | Icon size. |

## Home Assistant theme example

```yaml
my-theme:
  modes:
    light:
      --tdmm-accent: "#ff6600"
      --tdmm-progress: "#ff6600"
      --tdmm-text: "#ff6600"
      --tdmm-text-secondary: "#ff6600"
      --tdmm-bg: "#ff6600"
      --tdmm-chip-bg: "#ff6600"
    dark:
      --tdmm-accent: "#ff6600"
      --tdmm-progress: "#ff6600"
      --tdmm-text: "#ff6600"
      --tdmm-text-secondary: "#ff6600"
      --tdmm-bg: "#ff6600"
      --tdmm-chip-bg: "#ff6600"
```

## Per-card `theme` keys

```yaml
type: custom:tdmm-printer-card
device_id: <device id>
theme:
  accent: "#ff6600"
  radius: 8
  density: compact
```

Supported keys (numbers are pixels):

- `accent`
- `progress`
- `text`
- `text_secondary`
- `bg`
- `chip_bg`
- `radius`
- `font_family`
- `font_size`
- `icon_size`
- `density`
- `icon_set`

## Density

| Density | Gap |
| --- | --- |
| `compact` | `4px` |
| `normal` | `8px` |
| `comfortable` | `12px` |
